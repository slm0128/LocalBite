# ⚠️ WICHTIG: KEINE DIAGRAMME!!!!!

## 🎯 Fokus & Darstellung

* **Szenarien statt Diagramme:** Die Customer Journey soll als echtes Szenario durchgespielt werden (z. B. Kunde durchläuft den kompletten Abo-Workflow).
* **Mockups mit Screenshots:** Zur Visualisierung Mockups nutzen (eventuell ein passendes Plugin verwenden).
* **Fokus aufs Frontend:** Es wird ausschließlich das Frontend / UI gezeigt.

## 🗺️ Customer Journey & UX

* **Customer Journey ist Priorität!**
* **Personas anwenden:** Die Zielgruppe und deren Bedürfnisse genau im Blick behalten (Referenz: Fach *Barrierefreiheit*).
* **Typischer Nutzerfluss:**
  1. Kunde sucht die Website.
  2. Kunde registriert sich.
  3. Kunde klickt sich durch das Angebot (Website/Prototyp erstellen).

## ⚙️ Betreiber-Seite & Perspektiven

* **Perspektivenwechsel (Switch):** Es soll gezeigt werden, wie sich die Sichten unterscheiden. 
  * *Wie sieht die Kundenansicht (Abo) aus?*
  * *Wie sieht die Landwirt-Sicht aus?*
* **Parallele Darstellung:** Eventuell Sichten parallel aufbauen oder im Szenario fließend hin- und herwechseln.

## 🎤 Präsentations-Regeln

* **Teamwork:** Jeder aus der Gruppe soll/muss etwas sagen!
* **Zeitrahmen:** Die Präsentation dauert einmal **5 Minuten**. (Kurz, prägnant und auf den Punkt!)
